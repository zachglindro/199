# CRDTs: Enabling Collaboration in Decentralized Systems

Modern real-time collaborative applications require low-latency offline capabilities and data ownership. This presentation breaks down how CRDTs make conflict-free data replication possible across distributed systems. 

This deck covers:
- Centralized vs. Decentralized architectures
- Strong Consistency vs. Eventual Consistency
- Operation-Based (CmRDT) vs. State-Based (CvRDT) models
- Real-world adoption (Apple Notes, Zed Editor)
- Local-first software paradigms
